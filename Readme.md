## How to setup locally

1. Install ffmpeg on your system
2. Create .env file in the form of .env.example
3. `npm install`
4. `npm run dev`

By default the port is 3001 and allowing cors on 3000.
To change these values, add the following variables also 

1. `PORT=`
2. `NEXT_PUBLIC_APP_URL=http://localhost:3000`
